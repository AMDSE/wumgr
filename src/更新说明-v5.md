# v5 更新说明

- 现有 v4 设备发现、精确匹配、历史候选、批量下载、WUA 静默安装和驱动更新保护功能保留。
- 嵌入 **bezzad/Downloader 3.1.2**（仅 `net462`，固定 NuGet 包与 DLL 哈希）；没有外部包依赖，3.2+ 不兼容旧框架。
- 下载采用 8 块、4 并发，内存 buffer 上限 4 MiB；256 KiB 以下或无 Range 自动单流，并显示速度、总体及分块进度。
- 取消／失败落盘保留 `*.part`、`*.resume.xml`；相同目录同 URL 在服务器支持 Range 且存在有效强 ETag 或 Last-Modified 时可恢复。无校验标识、资源变化时重新下载；不承诺进程崩溃续传。
- 成功仅在长度符合预期且非空后原子覆盖正式文件。
- 3.1.2 默认修改 TLS 证书策略；适配层恢复系统 TLS 1.2 和证书校验并限制并发。
- 发布包同时包含运行所需 `Downloader.dll`、第三方 MIT 许可证和归属说明；源码包排除 packages 缓存、bin/obj 与测试 exe，并提供 v5 专用 ZIP。
- WUA 安装仍使用 Windows 系统缓存，可能另行下载；多线程 HTTP 下载不代表 WUA 安装下载。
- Linux 仅完成自动化测试；Windows 实机 WUA、WMI、微软 CDN、管理员权限与策略效果待验收。
