# Windows 实机验收清单（v8.0）

以下检查须在可回滚的 Windows 10／11 测试设备执行。Linux／Mono 不证明 Windows 更新安装、微软 CDN 或策略实际生效。

## 设备与下载

1. 普通权限打开不自动触发 UAC，静默安装默认不勾选，保护默认不改动。演示模式禁止扫描、下载、安装和策略修改。
2. 扫描确认 WMI 正确读取 Present 设备、硬件／兼容 ID、PNPClass、问题代码和当前驱动版本；WMI 失败不得伪报空扫描成功。
3. “设备搜索”列出无可用驱动的本机设备；名称、厂商、实例 ID、硬件 ID 搜索有效，驱动匹配使用完整 ID，不猜测型号、不按子串误配。
4. 自动下载每设备至多一个候选，同一更新不重复；跳过被取代、无地址、未知版本和不高于已知当前版本的候选，先确认再下载。
5. 保留中文分类、型号／版本、历史单选、单项／批量下载和目录选择。历史只限当前更新源返回候选，不承诺完整。
6. 验证 HTTP 错误、空响应、长度、磁盘不足、只读目录、重复下载、断网和取消清理 .part；默认只下载不得更改驱动或策略。

## 安装

7. 非管理员明确提示以管理员身份重开，不假称已安装。确认框列出实际驱动项目与闪屏／断网／重启风险。
8. 在可回滚非关键设备上确认 WUA 精确驱动身份与类型、未安装／未隐藏，使用系统缓存而非执行本地下载文件；EULA 未接受则拒绝。
9. 下载失败项不得安装，安装失败独立报告，后续项可继续；总结果与单项结果不能把部分失败视为成功。
10. 扫描或系统缓存下载期间取消，不应继续开始安装；安装期间取消等待当前调用完成，保留已安装项与重启需求，阻止后续项。不强杀服务、不回滚已完成项。
11. 需要重启时明确提示，不自动重启。安装日志写失败不能将成功变为失败。

## 保护与恢复

12. 安装成功后仅询问是否打开保护设置，不自动开启；设置入口可以读取当前状态。
13. 管理员模式分别测试原值不存在、DWORD 0、DWORD 1：首次开启先备份，重复开启不覆盖，恢复准确还原或仅删除该值，不删除 WindowsUpdate 键。
14. 设置外部改为其他值后拒绝覆盖恢复；没有本工具备份的已开启策略不能擅自关闭；备份损坏、非 DWORD、权限不足、写失败均明确报错。
15. 仅写 ExcludeWUDriversInQualityUpdate，安全补丁和 Windows Update 服务保持启用，无新增服务、计划任务或自启动。
16. UI 明确全机策略、仅排除常规质量更新中的驱动：不拦截安全／关键更新中的系统驱动、功能更新动态驱动，不保证拦截其他安装来源；家庭版不承诺生效，组织策略可能覆盖。
17. 重启后核对注册表／组策略和 Windows Update 的实际行为；保护可能影响工具查询，恢复后重试，不把写值成功当作全面阻断。

## 界面与交付

18. 在 100%、150%、200% 缩放及最小窗口尺寸确认控件、安装勾选、保护按钮、历史、设备搜索、取消和重启提示可读。
19. GPLv3、上游、图标归属与对应源码齐备；最新自动化日志随包，演示截图不是实机扫描证据。

## v8 常见设备清单

20. 更新源零候选或失败时，显卡、网卡、声卡、蓝牙、存储、键鼠、显示器和摄像头等仍显示；可读的处理器及芯片组功能控制器也保留。对照设备管理器核验已安装版本、提供商、日期，不把空字段当成“未安装”。
21. 主界面不罗列音频播放/录音端点、蓝牙枚举器、虚拟网卡/VPN、USB集线器、PCI桥/根端口、ACPI计时器或通用HID子节点。同一CPU的逻辑核心折叠，但两只同型号鼠标、两块同型号显卡等真实实例仍分开。
22. 设备搜索仍保留完整原始清单，包括未知/异常设备。只有一项匹配候选时，其余无候选常见硬件仍可见；全选不选无候选行。主界面可搜索已安装驱动版本和提供商，中英切换保留筛选与历史选择。
23. 多种Windows语言、不同OEM命名的芯片组/USB/HID设备核验筛选；名称启发式可能漏掉少见控制器，须从设备搜索核对，不承诺覆盖所有第三方虚拟驱动。
