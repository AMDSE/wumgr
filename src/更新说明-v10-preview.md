# v10 预览版：干净的圆角与现代勾选

这版接着 v9 做视觉修正，保留双语、侧栏分类、搜索、历史候选及原有下载和安装逻辑。以 GitHub 预览版发布，不替换稳定版 v8。

## 圆角外不再套方框

按钮、搜索容器、摘要和设备卡片使用统一的圆角背景绘制：外角呈现父容器颜色，而不是留下整块矩形底色；同时移除系统边框样式，避免原生方框与圆角边线叠加。键盘焦点改为圆角描边，仍可辨认当前操作位置。

## 复选框换新

设备选择、“扫描时包含历史版本”和“下载后后台静默安装”改为绿色圆角复选框，白色勾号更清晰；未选中、悬停、焦点、禁用和不确定状态分别绘制。历史版本的单选圆点同步更新。

这里只替换绘制，仍继承原生 CheckBox / RadioButton：不重写勾选、单选互斥、Tab 导航、空格键、事件或可访问性角色。演示模式仍禁用真实扫描、下载、安装及策略操作；静默安装仍默认关闭，未降低权限或确认要求。

## 预览与验证

包内包含最新中英文真实窗体截图、完整源码及测试日志；截图为 Linux / Mono 的演示数据，不是 Windows 扫描结果。布局覆盖中英文和 1024×680、1280×860、1380×1000 窗口，新增现代控件绘制与交互回归；其它设备、候选、下载、取消、安装和策略测试保持原有覆盖。以 `最终测试日志-v10-preview.txt` 中的实际结果为准。

本轮未执行真实驱动安装或策略变更。Windows 10 / 11 实机、系统更新服务和高 DPI 验收仍待完成，不能将 Mono 的通过结果等同于 Windows 实机通过。框架仍为 WinForms + .NET Framework 4.8，未引入大型运行时。

## 使用

解压后在 Windows 10 / 11 运行 `程序\wumgr.exe`。双语在顶栏切换；Ctrl+F 搜索，搜索框内 Escape 清空，空闲正式模式 F5 扫描。默认仅下载，需要安装或修改保护策略时才使用管理员权限。

程序目录和完整 ZIP 均继续执行 5,000,000 字节上限检查，随包保留许可证、依赖归属、源码与校验清单。
