# v4.0 更新说明

- 新增本机设备清单与设备名称、硬件／兼容 ID 搜索；可选取匹配驱动下载。
- 新增“自动搜索下载”：发现设备后保守筛选可下载候选，确认后批量下载。
- 新增主动勾选的“下载后后台静默安装”：需管理员权限，使用 WUA，不执行本地文件，不自动重启。
- 新增“驱动更新保护”：成功安装后可选择进入设置；仅排除常规质量更新的驱动，先备份、可恢复，不关闭系统安全更新。
- 保留中文卡片、型号和版本显示、历史候选单选、下载目录、取消与日志。

保护不是全面阻断：随安全／关键更新提供的系统驱动、功能更新动态驱动不在阻断范围内，其他安装渠道也可能更新驱动。组织策略可覆盖，家庭版不承诺生效。

当前仅在 Linux／Mono 完成可执行的自动化与模拟测试；Windows 真实设备发现、WUA 安装、微软 CDN 和策略实际效果待实机验收。
