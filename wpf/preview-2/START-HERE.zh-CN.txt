WuMgr WPF Preview 2 — 请从 WuMgr.exe 启动

1. 解压整个压缩包，双击“程序\WuMgr.exe”。不要直接在压缩包内运行，也不要只复制一个 EXE。
2. 启动器不依赖 .NET。每次启动检查 .NET Framework 4.8 或更高版本；已安装则直接打开 WPF，不联网下载运行环境。
3. 如果缺少环境，自动从微软 HTTPS 下载约 116 MiB 的 .NET Framework 4.8 离线安装包，验证微软数字签名后请求 Windows 管理员授权并安装。需要联网和管理员权限；UAC 不能也不会被绕过。
4. 安装成功且不需重启时自动打开 WPF；需要重启时只提示手动重启，不自动重启。重启后再次运行 WuMgr.exe。
5. 下载失败、签名错误、拒绝授权或安装失败时停止，不强行运行。解决网络/权限等问题后可重新运行。
6. 自动补装面向 Windows 10 1607 及以后、Windows 11 的 x86/x64 环境。ARM64 缺少环境时暂不自动补装；已有兼容 .NET Framework 环境时可尝试启动，但未作 ARM64 实机验证。
7. 本次只补装程序运行环境，不自动安装驱动、不自动开启更新搜索、不更改更新保护策略。

程序仍为预览版。已完成交叉编译和逻辑测试，缺少环境的 Windows 实机自动安装、UAC、重启与 WPF 界面仍需验收。
详细说明见 RUNTIME-BOOTSTRAP.zh-CN.md 和 README-WPF.zh-CN.md。
